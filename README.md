Concept development (PoC) using Method Channels to communicate with Flutter with native code in Kotlin, implementing the management of secure URIs (FileProvider) to invoke the native sharing dialogue of the operating system (Android Intent Chooser).

**Architecture**
- Bloc as state management 
- i18 AppLocalzation 
- Method and Event Channels
